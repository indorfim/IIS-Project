# Исходные данные

Сюда кладутся исходные документы вашей темы — PDF, TXT, MD. Собираются дома
после практики 1, используются и коммитятся в репозиторий начиная с практики 2:
корпус сдаётся вместе с кодом. Этот файл при индексации пропускается.

Бандл загружается в СДО не больше 20 МБ. Если с корпусом он выходит больше,
работа сдаётся ссылкой на репозиторий или на бандл в облачном хранилище.
В публичный репозиторий не кладите документы, которые нельзя распространять.

Собранные документы не удаляйте даже при сужении объёма на практике 5: лишние
источники просто перестают индексироваться, но остаются в репозитории.
